# Ucho Jazzowe — UX concepts

Pięć niezależnych, jasnych kierunków wizualnych dla aplikacji **Ucho Jazzowe**.

To repozytorium jest celowo oddzielone od aplikacji muzycznej. Mockupy nie zawierają audio, mikrofonu ani właściwej logiki ćwiczeń.

## Koncepcje

1. **Editorial Jazz** — elegancki, albumowo-redakcyjny klimat
2. **Blue Note Modern** — najbardziej produktowy i czytelny
3. **Warm Studio** — ciepły, miękki, przyjazny
4. **Bauhaus / Cézanne** — najbardziej charakterystyczny wizualnie
5. **Minimal Premium** — spokojny, precyzyjny, oszczędny

Otwórz `index.html`, aby porównać wszystkie wersje.

## Założenia UX

- jednoznaczny CTA: **Dzisiejszy trening**
- mniej decyzji na wejściu
- szybkie „Kontynuuj”
- widoczny postęp
- sekcja **Do poprawy** oparta o najczęstsze pomyłki
- czytelna nawigacja mobilna i desktopowa
